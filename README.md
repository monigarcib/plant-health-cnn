# Casa Blanca Predict

Sistema de clasificación de plantas utilizando visión por computadora y Machine Learning.

## Descripción

Este proyecto tiene como objetivo detectar automáticamente el estado de salud de las plantas mediante imágenes, clasificándolas en:

- Planta sana
- Planta marchita

La propuesta surge a partir de la necesidad del vivero **Casa Blanca** de contar con una herramienta que facilite la detección temprana de problemas en sus plantas.

---

## Tecnologías utilizadas

- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Google Colab

---

## Funcionamiento

El sistema sigue el siguiente flujo:

1. Captura o carga de imagen
2. Preprocesamiento
3. Clasificación mediante CNN
4. Resultado final

---

## Dataset

El dataset está compuesto por imágenes obtenidas de:

- Fotografías propias del vivero
- Fuentes abiertas en internet

Clases utilizadas:

- Sana
- Marchita

---

## Métricas utilizadas

- Accuracy
- Precision
- Recall
- F1-score

---

## Modelo utilizado

Se implementa una red neuronal convolucional (CNN) para identificar patrones visuales en las plantas.

---

## Objetivo

Desarrollar una herramienta que ayude a automatizar la detección del estado de salud de las plantas y contribuya al monitoreo eficiente en viveros.
